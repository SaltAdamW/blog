# 1.0.0：周报发布前逐轮追问

1. **真实追问**：定时周报发布前，由追问者和回答者逐轮核对具体场景、替代方案、机制、数据与适用边界。
2. **意见落实到改稿**：高、中优先级问题生成深化建议，局部返修后重新核对事实与解释，不只输出评分或问题清单。
3. **中断可继续**：保存每轮结果和稿件哈希，超时从断点恢复；未解决问题不能通过反复重试碰运气放行。
4. **发布入口一致**：每周任务、每日补稿和手动发布都需完成追问；已经上线的旧文章不会因此自动改写。
5. **源码与运行数据分离**：发布包包含源码、测试和示例配置，不含原文缓存、文章草稿、运行日志或凭据；示例配置默认关闭自动发布。

本版接入范围为定时周报及补稿。独立长文自动流程仍保留原有框架和成稿确认，尚未接入双角色编排。模型互审不是独立实验复现，也不保证事实判断不会出错。

首次使用请复制 `config.example.json` 为本地 `config.json`，配置环境并先运行测试。安装定时器会周期性消耗模型额度；向博客发布另需对应仓库授权。
